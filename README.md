# ULOV pilot builds

Android APKs published automatically by CI. Version 0.1.140 (build 140), source commit `e55b861`.

Install once: `ulov-customer-arm64-v8a.apk` (customer) or `ulov-driver-arm64-v8a.apk` (driver); most phones use arm64-v8a, older ones armeabi-v7a. After that the app offers updates itself.

This repository holds only built APKs, not source code.
